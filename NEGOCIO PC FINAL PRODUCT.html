Here is the catalog of 100% free, production-ready APIs you can integrate for hyper-local early warning, along with real snippets and integration methods.

1. Open-Meteo (Weather & Soil Moisture)

FREE · NO KEY

Provides hourly rain rate, soil saturation (key for landslides/flash floods), temperature, pressure, and high-altitude Himalayan elevation models.

fetch(`https://api.open-meteo.com/v1/forecast?latitude=30.73&longitude=79.06¤t=temperature_2m,precipitation,surface_pressure&hourly=soil_moisture_0_to_7cm&forecast_days=2`)
  .then(res => res.json())
  .then(data => console.log(data));

2. USGS Earthquake API (Seismic Mass-Movement)

FREE · NO KEY

Live seismic event feed with radial search. Captures sudden tectonic shocks or high-magnitude rockslide ground vibrations.

fetch(`https://earthquake.usgs.gov/fdsnws/event/1/query?format=geojson&latitude=30.73&longitude=79.06&maxradiuskm=300&minmagnitude=2.0`)
  .then(res => res.json())
  .then(data => console.log(data.features));

3. RainViewer API (Precipitation Radar Tiles)

FREE · NO KEY

Provides global composite Doppler radar frames (past 2 hours + nowcasts) to project live rain bands onto Leaflet/MapLibre maps.

fetch(`https://api.rainviewer.com/public/weather-maps.json`)
  .then(res => res.json())
  .then(meta => {
    const frame = meta.radar.past.pop();
    L.tileLayer(`${meta.host}${frame.path}/256/{z}/{x}/{y}/4/1_1.png`).addTo(map);
  });

4. IMD Official APIs (Mausam.imd.gov.in)

GOV FREE · BACKEND PROXY

Official India Meteorological Department endpoint. Because IMD APIs enforce IP whitelisting & lack browser CORS headers, query them via a lightweight serverless worker or Node/Python gateway.

// On your Node.js / Python backend:
// Endpoint: https://api.imd.gov.in/api/v1/cityforecast?id=42111
// Forward normalized JSON to your frontend client.
